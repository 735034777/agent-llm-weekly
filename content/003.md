### 1. AgentCollab：小模型走不动时，再让大模型接手

`会议论文 · EMNLP 2026 主会 · 已发表 · arXiv v2 更新（初稿 3 月 27 日） 2026-10-30` · EMNLP 主会 / 推理效率

多轮 Agent 的单步推理便宜，不代表整项任务便宜：小模型可能不断搜索、反复试错。AgentCollab 用执行过程中的自我检查判断是否取得进展，停滞时切换到更强模型；多次受阻时，增加大模型连续介入的步数，并设置预算上限。它不需要另训一个路由器。

论文在 DDV2 和 WebSailor 上测试。以 DDV2 的 BrowseComp_zh 为例，协作方案准确率为 33.9%，全程大模型为 34.6%，端到端速度为后者的 1.36 倍；使用 Pangu 7B／38B、最多 40 轮、本地 Ascend 910B3 推理。这给工程实践一个可检验的方向：把算力分配与任务是否推进联系起来。

这些是作者实验结果。进展判断本身会出错，论文也观察到 WebSailor 的误判更多；本地速度收益不能直接等同于云 API 省钱比例。本刊首次介绍该成果，已核对 10 月 EMNLP 主会论文集，日期另列 10 月 30 日的 arXiv 修订。

[原文与发表信息](https://aclanthology.org/2026.emnlp-main.2400/) · [会议版 PDF](https://aclanthology.org/2026.emnlp-main.2400.pdf) · [arXiv 版本记录](https://arxiv.org/abs/2603.26034)

### 2. Agent 答对了，还要检查它是怎么做到的

`会议论文 · Findings of EMNLP 2026 · 已发表 · 会议论文集日期起点（10月24—29日） 2026-10-24` · EMNLP Findings / 过程评测

《Procedural Blind Spots in Agent Evaluation》梳理了 Agent 评测的过程盲区：很多评测仍以任务完成为中心，过程检查往往只检查局部，而 Agent 对用户说了什么、这些说法是否有执行证据，覆盖尤其不足。

值得借鉴的是统一审计视角：把行动、观测、规则与对用户的陈述联系起来。对实际产品，可以据此补查“声称完成的操作是否真的发生”，而不只给最终回答打分；这是本刊根据论文框架提出的应用建议。

这是一篇综述与覆盖分析，发表于 Findings，不能视为某个新系统胜过所有基线的实验。Anthology 只给出发表月份；此处按 PDF 标注的会议论文集日期起点编目，不把它当作精确的首次上线日。

[原文与发表信息](https://aclanthology.org/2026.findings-emnlp.1162/) · [会议版 PDF](https://aclanthology.org/2026.findings-emnlp.1162.pdf)

### 3. Codex 的沙箱：把执行边界交给操作系统

`研究博客 · OpenAI Engineering · 官方工程博客 2026-11-18` · 执行安全 / 编程 Agent

OpenAI 的《Inside the Codex sandbox》介绍了文件、网络与子进程权限如何落到操作系统层面。文章选择利用原生系统机制，让 Agent 在熟悉的开发环境里运行，同时约束命令及其派生进程能改动和连接什么。

对做 Agent 的人，值得读的是模型决策与执行权限的分工，以及跨 macOS、Linux、Windows 统一权限配置的实现取舍。它提供的是系统设计经验，不能只用一句提示词替代这些执行限制。

沙箱不是全面的隐私隔离：文中工作区配置仍允许较广泛的文件读取，也讨论了可写依赖被用户的沙箱外工具再次执行的风险。这是官方工程说明，不是同行评审论文或本刊独立安全审计。

[原文与发表信息](https://openai.com/index/inside-the-codex-sandbox/)

### 4. Gemini 4 Neon 发布：面向长任务的新模型

`公告／报道日期 2026-11-18` · 模型发布 / Google

Google 发布 Gemini 4 Neon，提供 100 万 token 上下文，重点面向软件开发、知识工作和科学任务。公告定价为每百万输入 token 3 美元、输出 15 美元，缓存输入为 0.15 美元；同时开始向 Gemini API、企业服务，以及部分 Pro／Ultra 产品入口推出。

官方强调任务中途接受用户修正、长流程工具使用与压缩上下文的能力；实际可用入口和订阅范围以公告及账户显示为准。

### 5. Project Genie 开放 Genie 4：边探索，边改世界

`公告／报道日期 2026-11-18` · 世界模型 / 互动创作

Google 向符合条件的 AI Ultra 用户推出搭载 Genie 4 的 Project Genie 更新：探索过程中可以用文字改变天气、角色或事件，并加入随场景变化的原生音频。新版创作 Agent 帮助搭建世界，社区图库则支持分享、探索和再创作；Pro 用户可加入候补名单。

### 9. Anatomy：让科普插图变成可以操作的小装置

`本期发现／资料快照 2026-11-23` · Skill / 交互式科普

⭐ 28,723（2026-11-23 快照） · MIT；生成素材和第三方内容需另核权利。

输入一个机械或物理概念，让编程 Agent 生成可操作的等轴测装置：波纹水槽能改变波形，发动机可以拆开看内部。Anatomy 提供技能说明、绘图组件和检查工具，适合做机制讲解、课程演示和网页中的交互插图。它更擅长机器、仪器等有具体结构的对象。

<p align="center"><a href="https://raw.githubusercontent.com/wheresryan22/anatomy/1482e8469b0a9e0d8cc18ea2740a01423d29ae80/.github/assets/ripple-tank.webp"><img src="https://raw.githubusercontent.com/wheresryan22/anatomy/1482e8469b0a9e0d8cc18ea2740a01423d29ae80/.github/assets/ripple-tank.webp" alt="等轴测波纹水槽，上方双振源在水面产生干涉波纹，灯光把图样投向下方底板。" width="800"></a></p>

*作者的波纹水槽交互图示例；此处展示原图，并非本刊运行结果。 · 图源：[Ryan / Anatomy](https://github.com/wheresryan22/anatomy/blob/1482e8469b0a9e0d8cc18ea2740a01423d29ae80/README.md)*

**上手：** 先浏览仓库示例，再按 README 为自己的 Agent 安装技能；从波纹水槽或简单仪表开始，比直接要求复杂机械更容易判断结果是否合理。

工具要求 Node.js 20.10+；自动截图与审查需 Chrome／Chromium，动态着色需 WebGL。生成过程仍依赖所用编程 Agent；3D 模式标为 beta，复杂图可能耗时较长。

[GitHub](https://github.com/wheresryan22/anatomy) · [文档快照](https://github.com/wheresryan22/anatomy/blob/1482e8469b0a9e0d8cc18ea2740a01423d29ae80/README.md)

### 10. PaddleOCR：把扫描件、表格和公式变成可处理的数据

`本期发现／资料快照 2026-11-23` · OCR / 文档解析

⭐ 93,018（2026-11-23 快照） · Apache-2.0；模型、数据及第三方素材另按对应条款。

处理 PDF 或扫描图片时，常常不仅要识别文字，还要保留版面、表格和公式。PaddleOCR 提供文字识别、PP-StructureV3 文档结构解析及视觉语言模型路线，可输出 Markdown 或 JSON，适合文档数字化、资料检索和数据预处理。

不同管线、推理后端和设备的依赖有差别；仓库提供 CPU、GPU 等部署路径，不能用“支持 CPU”推断所有模型都能低成本运行。复杂文档仍需抽查阅读顺序和表格结构。

### 11. LeRobot：从示范数据到机器人策略的一套工具

`本期发现／资料快照 2026-11-23` · 机器人 / 具身智能

⭐ 29,031（2026-11-23 快照） · Apache-2.0；外部策略权重、数据集与硬件资料另核许可。

LeRobot 将机器人接口、示范数据、策略训练和评测放进同一个 Python 工具库。它用视频或图片配合状态／动作数据记录过程，支持多类机器人及学习策略。对于想进入具身智能的人，可以先理解公开数据和仿真评测，再决定是否购买、组装硬件。

### 12. SAM 3：用文字或示例圈出图像和视频中的对象

`本期发现／资料快照 2026-11-23` · 视觉分割 / 开放权重

⭐ 12,376（2026-11-23 快照） · 自定义 SAM License，含使用限制；不等同于 MIT／Apache 开源许可。

想把画面中的“企鹅”全部找出来，或在视频里持续跟踪它们，SAM 3 提供文字、点、框、掩码和示例等提示方式，输出对象掩码与相关结果。仓库包含图片、视频及交互修正 notebook，适合标注辅助、视觉研究和编辑工具开发。

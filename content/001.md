### 3. Hermes Agent v0.23.0：让多种客户端共用一份会话

`版本发布 2026-11-05` · 高 star / 会话管理 / 通用 Agent

⭐ **262,829** · 查询日期 2026-11-12 · [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)

Hermes Agent 支持记忆、技能和多种交互入口。v0.23.0 强化由同一网关统一管理会话，让终端、桌面、消息入口和定时任务共享队列与历史，并提供浏览器工作区及可插拔的子 Agent 委派。

### 4. LangGraph 1.2.20：让恢复操作对应到正确的中断

`版本发布 2026-11-05` · 人工介入 / 状态恢复 / 版本更新

⭐ **44,838** · 查询日期 2026-11-12 · [langchain-ai/langgraph](https://github.com/langchain-ai/langgraph)

LangGraph 核心包 1.2.20 为同一任务中的每个 interrupt()（暂停任务、等待外部输入的调用）提供独立 ID，并增加拒绝过期中断回答的严格恢复模式。本期引用核心包的 Release，不混用同一仓库里的 SDK 或 CLI 版本号。

**为什么值得看：** 对于需要人工确认、可能暂停多次的 Agent，恢复时把答复接到正确状态，是值得单独测试的正确性问题。

**适用范围与限制：** 这是执行状态管理的更新，不意味着模型推理能力提高。本刊未执行升级测试，接入前仍需核对调用方式与现有持久化状态的兼容性。

[官方 Release](https://github.com/langchain-ai/langgraph/releases/tag/1.2.20)

Anthropic 将跨会话记忆拆成原始记录、记忆笔记、知识表示和预先注入的上下文，并讨论 dreaming（在交互间隙整理记忆）机制。文章展示了用原始记录纠正错误笔记、整理 wiki 知识页面和调整注入内容的案例。

## 模型与研究

### 6. Harness-S：把不同执行系统的成功经验学进模型

`论文首发 2026-11-03` · Agent 训练 / 强化学习 / 预印本

执行系统（harness）指模型外围的提示、工具接口和运行规则。Harness-S 准备针对不同失败原因的系统变体，在基础系统的尝试全部失败时，用变体生成训练轨迹，再以强化学习更新同一模型。作者在 AppWorld、SWE-Gym 和 DBBench 中报告：回到原始系统后，训练收益仍能保留。

**为什么值得看：** 它将一个工程问题变成训练问题：更合适的工具接口或执行规则，能否帮助模型学到可迁移的行为，而不只是改善当次结果？

**适用范围与限制：** 结果来自论文设定的模型与环境，本刊未复现。比较总成本时还需计入变体构建、路由和训练，不能只比较最终执行次数。

[论文 v1](https://arxiv.org/abs/2611.04277v1) · [作者代码](https://github.com/DeepExperience/Harness-S)

### 7. Axion 1.0：从独立推理到工具交互的三阶段训练

`论文首发 2026-11-02` · 后训练 / Agent 模型 / 预印本

Axion 1.0 报告两阶段监督微调加强化学习的训练路线：先构造适合基础模型的推理数据，再加入可自动验证的工具任务，最后强化长程推理与环境交互。论文首次提交于 11 月 2 日，本期参考 11 月 3 日的 v2。

**为什么值得看：** 适合关注 Agent 模型训练的人阅读：重点看数据如何生成、验证和过滤，以及两类推理任务如何衔接，而不只看结果表。

**适用范围与限制：** 作者宣称开放权重之外的训练配方和代码；本期核查的是论文中的方法与开放声明，未逐项验证全部资源，也未复现性能。步骤少不等于训练成本低。

[论文 v2](https://arxiv.org/abs/2611.03233v2) · [论文全文](https://arxiv.org/html/2611.03233v2)

### 8. FrontierPhysics：评估从文献到研究产出的完整过程

`论文首发 2026-11-04` · 科研 Agent / 端到端评测 / 预印本

FrontierPhysics 用物理研究任务评估文献检索、研究计划、实验执行和结构化研究产出。作者结合确定性验证与专家制定的评分标准，试图同时衡量结果正确性和研究质量。

**为什么值得看：** 值得看的是它如何把“会回答问题”与“能完成研究过程”分开评价。设计自己的科研 Agent 测试集时，可以参考任务构成和评分依据。

**适用范围与限制：** “可发表性”是该基准定义下的评价，不等于通过真实期刊审稿。结果受任务选择、执行配置和评分标准影响，不能直接推断所有学科的研究能力。

## 本期动手

选一个你已经反复执行的 Agent 任务，固定模型、工具和预算，比较三种设置：不保留跨会话记忆、保存未经整理的笔记、保存可回查原始记录且经过整理的笔记。各组从相同历史快照独立开始，每个任务重复运行，避免组间泄漏经验。记录成功率、token（模型处理文本的计量单位）消耗、人工接手次数及错误记忆的再次引用次数；整理记忆的开销计入总成本。先做小样本探索。这是编辑建议，本刊未执行该实验，也不预设第三种一定更好。
